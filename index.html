Practicum, 2026 In progress

A risk-based readiness framework for post-quantum cryptography migration in web applications

Research project for my Practicum module. Quantum computing threatens the RSA and elliptic-curve cryptography behind TLS, APIs and code signing, and NIST has now standardised replacement algorithms (FIPS 203, 204 and 205). What organisations lack is a practical way to judge how ready their own web applications are to migrate. I'm building a framework that scores each cryptographic asset and ranks the migration work by risk.

Assets assessed
TLS/HTTPS certificatesAPI communicationsDatabasesBackupsCode signingCloud services
Scored on
Quantum vulnerabilityBusiness criticalityMigration complexityCrypto-agilityVendor support

Each asset gets a readiness level of High, Medium or Low. The method is Design Science Research backed by a systematic literature review, then validation on representative web application architectures. Proposal submitted August 2026.

FINDING-001Cloud infrastructure

Defence-in-depth AWS hardening of WordPress on Apache, PHP and MariaDB

Hardened and monitored Resolved ▶

MSc Cloud Architecture & Security module project (2026). I deployed a defence-in-depth AWS architecture (EC2, Security Groups, KMS, CloudWatch, SNS) hosting a production-style Apache/PHP/WordPress/MariaDB stack, secured end-to-end with TLS/Certbot. I assessed it with Nmap, Nessus, Nikto and WPScan for vulnerability scanning and web-layer testing, and Wireshark for traffic analysis, then triaged every finding by severity before remediating.
